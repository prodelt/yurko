# Картки джерел

Картка — запис про одне джерело в розділі «Джерела» наприкінці документа (`output.md`, фаза 6). Юрист за хвилину відкриває джерело, знаходить місце і бачить, що воно каже. У Word номер картки `[k]` стоїть у тексті проєкту на місці виноски чернетки, клік веде до картки; той самий номер — у рядку «Джерело» примітки до абзацу. У чернетці розбору блок веде до картки посиланням «Картка джерела».

## Картка

Одна картка — одне джерело (рішення, акт, закон, матеріал справи), хоч би скільки абзаців на нього посилалося. Порядок — за першою згадкою в проєкті. Заголовок — назва джерела словами, ключ закладки — латиницею.

```markdown
### Рішення Суду ЄС у справі IS, 23.11.2021 {#k-is}

**Про що.** <спір одним реченням>. <що вирішено одним реченням>. Для нас: <яку нашу тезу підтримує>.

**Відкрити.** [Рішення англійською, одразу на пункті 61](<URL з якорем>)

**Де шукати.** Пункт 61, фраза для пошуку (Ctrl+F): «quite obvious that the interpretation». Якщо сторінка не прокрутилась до пункту — натисніть посилання ще раз.

**Ключове речення.** «<переклад мовою документа>»
Оригінал: «<дослівно мовою сторінки>»

*Для подання:* <реквізит мовою провадження в стилі суду> ⟦S12⟧
```

- **Про що** — три речення, простою мовою, без номерів пунктів.
- **Відкрити** — посилання з підписом словами: що відкриється і якою мовою. Кілька місць одного джерела — кожне окремим рядком. Мова сторінки — англійська; національні джерела — мовою оригіналу. Шаблон — за таблицею нижче.
- **Де шукати** — номер пункту чи статті як орієнтир і **фраза з 3–6 слів** дослівно з цього пункту мовою сторінки: номер пункту Ctrl+F часто не знаходить (окрема клітинка таблиці, виноска з тим самим числом, злиплий індекс). Фраза не англійською — з перекладом у дужках.
- **Ключове речення** — одне речення, на якому стоїть наша теза: переклад і оригінал. Переклад — пара для перевірки (`phases.md`, фаза 4).
- **Для подання** — реквізит мовою провадження суду в його стилі для виноски у версії для подання, напр. «Arrêt du 6 octobre 2021, W.Ż., C‑487/19, EU:C:2021:798, point 45.»; зразок — рішення цього суду тією мовою (для Суду ЄС — той самий CELEX на EUR-Lex іншою мовою). Мова проєкту — мова провадження — рядка немає: реквізит уже у виносці чернетки. Номер опори `⟦S<n>⟧` стоїть лише в чернетці.
- **Матеріал справи** (ухвала суду, що звернувся, подання сторін) — «Відкрити»: назва документа і його сторінка в теці справи юристів, без мережевого посилання.

## Посилання за видом джерела

Перевірено 23.09.2026 з браузера. Сайт без якоря — лише сторінка і фраза.

| Джерело | Шаблон | Якір на пункт |
|---|---|---|
| Рішення Суду ЄС | `https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:6<рік>CJ<номер з 4 цифр>#point<N>`; об'єднані — за першим номером; або `?uri=ecli:<ECLI>#point<N>` | так; до ~2003 року — немає. Перше відкриття EUR-Lex якір губить — звідси «натисніть ще раз» |
| Висновок генерального адвоката | `…?uri=CELEX:6<рік>CC<номер>#point<N>` | так; фраза обов'язкова — поруч із номером стоїть виноска з тим самим числом |
| Справа Суду ЄС без опублікованого тексту | `https://curia.europa.eu/juris/liste.jsf?language=en&num=<C-номер/рік>` | ні; CURIA — лише запасний шлях |
| Регламент, рішення ЄС (текст ОВ) | `https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:3<рік>R<номер>#art_<N>` (рішення — `D`); мотив `#rct_<N>`; додаток `#anx_I` | так; мотиви — лише в тексті ОВ |
| Консолідована редакція | `…?uri=CELEX:0<рік>R<номер>-<ррррммдд>#art_<N>` | так |
| ЄСПЛ | `https://hudoc.echr.coe.int/eng?i=<itemid>` (itemid — `HEJUD` з API HUDOC за номером заяви) | ні |
| Закон Естонії | `https://www.riigiteataja.ee/akt/<globaalID>?leiaKehtiv#para<§>` (§ 29¹ → `para29b1`) | так |
| UK | `https://caselaw.nationalarchives.gov.uk/<суд>/<рік>/<номер>#para_<N>` | так |
| Нідерланди | `https://uitspraken.rechtspraak.nl/details?id=<ECLI>` | ні |
| BGH | PDF з `bundesgerichtshof.de` через пошук за номером справи; `#page=<N>` | лише сторінка PDF |
| Cour de cassation | `https://www.courdecassation.fr/decision/<id>` (Judilibre) | ні |
| Міжнародний Суд ООН | сторінка справи `https://www.icj-cij.org/case/<№>`; PDF — `#page=<N>` | лише сторінка PDF |
| Договір, резолюція ООН | `https://docs.un.org/en/<символ>`; статус — `treaties.un.org` | ні |
| Закон, договір України | `https://zakon.rada.gov.ua/laws/show/<код>` | ні |
| Суди України | `https://reyestr.court.gov.ua/Review/<id>` — відкривається лише з українського IP | ні |

Сайт, який не відкрився в прогоні, в картці лишається, якщо сторінка офіційна; рядок «Де шукати» тоді каже, що посилання відкривається лише з певних країн, а в `manual-queue.md` — рядок для власника.
